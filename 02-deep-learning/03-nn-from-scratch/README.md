# Neural Networks from Scratch

## Overview

为了熟悉神经网络内部工作原理，从零开始实现几个简单的神经网络模型，包括Perceptron、Adaline、MLP，它们在神经网络的发展史上具有里程碑意义。后来的CNN或者Transformer虽然复杂，但是它们的基本工作原理是类似的，比如：

* 矩阵运算和张量运算
* 线性变换和非线性变换组合
* 误差反向传播和梯度下降

## Perceptron

Perceptron只能完成线性可分的任务，所以选择Iris数据集，这是ML的果蝇。

## Adaline

Adaline也只能完成线性可分的任务，所以也选择Iris数据集，这是ML的果蝇。

## MLP

MLP是现代深度学习中最基本的计算单元之一，也是Transformer的一个核心组件。任务选MNIST，这是深度学习的果蝇。
